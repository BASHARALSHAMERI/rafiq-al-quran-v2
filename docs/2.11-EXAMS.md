# 2.11 Exams MVP


## Database (Prisma)




### Enums


- `ExamStatus`: `DRAFT`, `PUBLISHED`, `COMPLETED`, `CANCELLED`
- `ExamType`: `JUZ`, `FULL_QURAN`, `SURAH_RANGE`, `OTHER`
- `AttemptStatus`: `SCHEDULED`, `IN_PROGRESS`, `SUBMITTED`, `REVIEWED`


### Tables




#### `exams`


- `id` (PK)
- `organization_id` (FK -> `organizations.id`)
- `center_id` (FK -> `centers.id`)
- `circle_id` (FK -> `circles.id`, nullable)
- `title`
- `type`
- `max_score` (default 100)
- `pass_score`
- `status` (default `DRAFT`)
- `scheduled_at` (nullable)
- `created_by_id` (FK -> `users.id`)
- `created_at`, `updated_at`
- Indexes: `(organization_id, center_id, status)`, `(circle_id)`, `(scheduled_at)`


#### `exam_criteria`


- `id` (PK)
- `exam_id` (FK -> `exams.id`, unique)
- `memorization_score`, `tajweed_score`, `performance_score`
- `prompting_penalty`, `reminding_penalty`, `tajweed_penalty`


#### `exam_attempts`


- `id` (PK)
- `exam_id` (FK -> `exams.id`)
- `student_id` (FK -> `users.id`)
- `circle_id` (FK -> `circles.id`)
- `committee_notes` (nullable)
- `total_score` (nullable)
- `grade_label` (nullable)
- `status` (default `SCHEDULED`)
- `started_at`, `submitted_at`, `reviewed_at` (nullable)
- `evaluated_by_id` (FK -> `users.id`, nullable)
- `created_at`, `updated_at`
- Constraint: `UNIQUE(exam_id, student_id)`


#### `exam_attempt_breakdown`


- `id` (PK)
- `attempt_id` (FK -> `exam_attempts.id`, unique)
- `memorization_score`, `tajweed_score`, `performance_score` (nullable)
- `prompting_deductions`, `reminding_deductions`, `tajweed_deductions` (nullable)


## Backend API




### Routes


- `GET /exams`
- `POST /exams`
- `PATCH /exams/:id`
- `POST /exams/:id/publish`
- `GET /exams/:id/attempts`
- `POST /exams/:id/attempts`
- `POST /attempts/:id/score`


### RBAC


- **List exams / attempts**: `SUPER_ADMIN`, `CENTER_ADMIN`, `SUPERVISOR`, `TEACHER`
- **Create/Update/Publish exam**: `SUPER_ADMIN`, `CENTER_ADMIN`, `SUPERVISOR`
- **Create attempt**: `SUPER_ADMIN`, `CENTER_ADMIN`, `SUPERVISOR`, `TEACHER`
- **Score attempt**: `TEACHER`, `SUPERVISOR`
- **Blocked**: `PARENT`, `STUDENT` (403)


### Scoping


- `SUPER_ADMIN`: all org exams
- `CENTER_ADMIN` / `SUPERVISOR`: center scope enforced by server
- `TEACHER`: circle scope enforced by server
- Attempt creation requires active enrollment in `student_circle_enrollments`


### Validation and Rules


- Zod validation for query/body/params
- `passScore <= maxScore`
- Update allowed only when exam status is `DRAFT`
- Publish allowed only when exam status is `DRAFT`
- Score endpoint computes total server-side and sets `status = REVIEWED`


## Seed data


- 2 exams (one per center)
- Criteria records for each exam
- Attempts for seeded students
- Breakdown records for attempts
