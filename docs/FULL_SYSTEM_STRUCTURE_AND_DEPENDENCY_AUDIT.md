## 1. Project Overview

Rafiq Al-Quran is a multi-layer system:

| Layer | Technology | Purpose | Status |
|---|---|---|---|
| Backend | Node.js, Express, TypeScript, Prisma | API, RBAC, modules, persistence integration | Active |
| Frontend | React, Vite, TypeScript | Admin web app for SUPER_ADMIN and CENTER_ADMIN policy surface | Active |
| Flutter Mobile | Flutter, Riverpod, GoRouter, Dio | Teacher, supervisor, student, parent mobile role surface | Active |
| Database | Prisma + PostgreSQL | Schema, migrations, seed | Active; schema modified in working tree before this audit |
| Docs/Scripts | Markdown, TS scripts, BAT/PS1 | Documentation, backfills, smoke checks, launch helpers | Mixed active/manual review |

Important constraints honored:
- No database changes were made.
- No migrations were created.
- `backend/prisma/schema.prisma` was not edited.
- No source logic, permissions, web/mobile policy, finance, reports, follow-up, or business logic was changed.
- No deletion was performed.
