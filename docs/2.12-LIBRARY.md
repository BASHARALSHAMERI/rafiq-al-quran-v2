# 2.12 - Library MVP

## Overview
Library MVP adds managed file metadata and scoped access by organization/center/circle with server-enforced RBAC.

- Database: MySQL + Prisma
- Storage: local filesystem (`backend/storage/library`)
- API module: `backend/src/modules/library/*`
- Frontend page: `frontend/src/pages/LibraryPage.tsx`

## ERD (snippet)

```text
organizations (1) ---- (N) library_categories
centers       (1) ---- (N) library_categories

organizations (1) ---- (N) library_items
centers       (1) ---- (N) library_items
circles       (1) ---- (N) library_items
library_categories (1) - (N) library_items
users(created_by)  (1) - (N) library_items
```

## Prisma Models

### `library_categories`
- `id` PK
- `organization_id` FK -> `organizations.id`
- `center_id` FK nullable -> `centers.id`
- `name` varchar(120)
- `code` varchar(80)
- `created_at`, `updated_at`

Constraints/Indexes:
- `UNIQUE (organization_id, code)`
- `INDEX organization_id`
- `INDEX center_id`

### `library_items`
- `id` PK
- `organization_id` FK -> `organizations.id`
- `center_id` FK nullable -> `centers.id`
- `circle_id` FK nullable -> `circles.id`
- `category_id` FK nullable -> `library_categories.id`
- `title` varchar(200)
- `description` text nullable
- `file_name` varchar(255)
- `mime_type` varchar(120)
- `file_size` int
- `storage_key` varchar(255)
- `visibility` enum: `ORG | CENTER | CIRCLE`
- `status` enum: `ACTIVE | ARCHIVED`
- `created_by_id` FK -> `users.id`
- `created_at`, `updated_at`

Indexes:
- `(organization_id, created_at)`
- `center_id`
- `circle_id`
- `category_id`
- `status`
- `visibility`

## Storage Design

- Root: `backend/storage/library`
- Path template:
  - `<organizationId>/<centerId or org>/<YYYY>/<MM>/<generatedFilename>`
- DB stores metadata only (`storage_key`, `file_name`, `mime_type`, `file_size`)
- File bytes are never stored in DB

### Upload limits
- Max file size: `20MB`
- Allowed mime types:
  - `application/pdf`
  - `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
  - `image/jpeg`
  - `image/png`
  - `image/webp`

## RBAC + Scoping Rules (server-enforced)

### View/list/download
- Allowed: `SUPER_ADMIN`, `CENTER_ADMIN`, `SUPERVISOR`, `TEACHER`, `PARENT`, `STUDENT`
- Visibility rules:
  - `ORG`: visible to scoped users in organization
  - `CENTER`: visible only if center is in resolved scope
  - `CIRCLE`: visible only if circle is in resolved scope

### Categories management
- Allowed: `SUPER_ADMIN`, `CENTER_ADMIN`, `SUPERVISOR`

### Item write/update/archive
- Allowed: `SUPER_ADMIN`, `CENTER_ADMIN`, `SUPERVISOR`, `TEACHER`
- Teacher policy:
  - can manage only own uploads (`created_by_id == teacher.id`)
  - cannot upload `ORG` visibility

## Endpoints

### Categories
- `GET /library/categories?centerId=`
- `POST /library/categories`

### Items
- `GET /library/items?centerId=&circleId=&categoryId=&q=&visibility=&status=&page=&pageSize=`
  - Returns:
    ```json
    {
      "ok": true,
      "data": [],
      "page": 1,
      "pageSize": 10,
      "total": 0
    }
    ```
- `POST /library/items` (multipart/form-data)
  - fields: `title`, `description?`, `centerId?`, `circleId?`, `categoryId?`, `visibility`, `file`
- `GET /library/items/:id/download` (stream + content headers)
- `PATCH /library/items/:id`
  - updatable: `title`, `description`, `categoryId`, `visibility`, `status`, `centerId`, `circleId`
- `DELETE /library/items/:id`
  - soft delete (`status = ARCHIVED`)

## Curl Examples

## 1) Login
```bash
curl -X POST http://localhost:4000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"superadmin@rafiq.local","password":"Rafiq@1234"}'
```

## 2) List Items
```bash
curl "http://localhost:4000/library/items?page=1&pageSize=10" \
  -H "Authorization: Bearer <ACCESS_TOKEN>"
```

## 3) Create Category
```bash
curl -X POST http://localhost:4000/library/categories \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"name":"مواد الحفظ","code":"LIB-HIFZ","centerId":1}'
```

## 4) Upload File
```bash
curl -X POST http://localhost:4000/library/items \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -F "title=خطة الحفظ" \
  -F "visibility=CENTER" \
  -F "centerId=1" \
  -F "file=@C:/tmp/plan.pdf;type=application/pdf"
```

## 5) Download File
```bash
curl -L "http://localhost:4000/library/items/1/download" \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  --output downloaded-file.pdf
```

## 6) Archive Item
```bash
curl -X DELETE "http://localhost:4000/library/items/1" \
  -H "Authorization: Bearer <ACCESS_TOKEN>"
```
