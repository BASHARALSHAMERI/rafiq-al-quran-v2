# Reports Roadmap

## Goals
Reports must be:
- printable
- useful for decision-making
- role-aware
- donor-friendly
- finance-ready
- visually professional

## Priority Reports

### REPORTS-PRINT-1 — Circle Report
Printable report for a circle:
- center
- circle
- teacher
- students count
- attendance
- memorization progress
- review progress
- exams
- notes/recommendations

### REPORTS-DONOR-1 — Donor Impact Report
For supporters:
- supported circle
- number of students
- achievements
- attendance
- progress
- photos/summary if available
- financial support summary if linked

### REPORTS-FINANCE-1 — Finance Reports
Required:
- General Ledger
- Trial Balance
- Statement of Activities
- Statement of Financial Position
- vouchers
- expenses
- donations
- payroll/rewards

### REPORTS-EXECUTIVE-1 — Executive Reports
For general management:
- centers comparison
- student growth
- completion rates
- teacher performance
- finance health
- risk alerts

## Print Design Requirements
- Arabic RTL
- clean header
- logo/association info
- filters summary
- tables readable on A4
- signatures/footer if needed
