```

│  ☰  رفيق القرآن             │  ← العلامة التجارية
```

- ألوان متناسقة

## 📱 التجاوب (Responsive)

### Desktop (> 1024px):
- Sidebar ثابتة (260px)
- Header يبدأ بعد Sidebar
- المحتوى يتكيف مع المساحة

### Tablet (768px - 1024px):
- Sidebar تختفي (overlay)
- زر ☰ لفتح القائمة
- كل شيء يعمل بشكل طبيعي

### Mobile (< 768px):
- Sidebar كـ overlay كامل
- Header مبسط
- المحتوى يأخذ العرض الكامل
- أزرار أكبر للمس
